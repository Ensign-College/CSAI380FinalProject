## Purpose:

Give your project a memory. This week you add the two stateful services the STEDI application depends on — Redis for sign-up/log-in state and MySQL as the operational data store — and prove their data survives pod replacement using PersistentVolumeClaims. You will run the application before and after persistent storage exists so you can see exactly what problem a PVC solves, then connect to the database from your own machine with MySQL Workbench.

## AI Ops in This Assignment:

- **(a) Use an agent to do the ops.** Put an AI agent in your troubleshooting loop this week: ask it to draft the `volumeClaimTemplates` TODO, explain the difference between a headless service and a ClusterIP service, or diagnose a `Pending` PVC or a CrashLooping StatefulSet from `kubectl describe` output you paste in. Verify every answer against the live cluster before acting — the agent can't see your namespace; you are its eyes, and you own the result.
- **(b) Build infrastructure that AI operations run on.** Durable state is the backbone of AI systems: vector databases, feature stores, model registries, and training checkpoints all live on exactly the StatefulSet + PVC pattern you are practicing. Redis in particular is the standard low-latency store for online features and caching at inference time — a model can't score a request quickly if its features aren't milliseconds away.

6. Add an **AI Ops reflection** section to `week-2-evidence.md` with two short parts:

7. Update `architecture.md` to **v2**: the diagram now shows Redis and MySQL running in Kubernetes with persistent volumes, and marks which components are live versus planned.

> **Parking between work sessions:** you just proved the principle — data on PVCs outlives compute. Between sessions, `kubectl scale deployment,statefulset --all --replicas=0 -n <your-namespace>` parks everything; your MySQL rows and Redis keys stay on their volumes, and weeks 3–5 build on this same data. Scale back to 1 to resume. Never delete a PVC unless you intend to destroy its data.
